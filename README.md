# AurionXI Smart Contracts

AurionXI is a modular BSC smart-contract ecosystem built with an EIP-2535 Diamond architecture.

This public repository is provided for transparency and community review. It contains the Solidity source code, interfaces, libraries, and Hardhat configuration used for the AurionXI smart-contract system.

## Modules

- Core Diamond
- Token Diamond
- Trade Diamond
- Treasury Diamond
- Analytics Diamond
- AI Diamond
- SBT Contract
- Token Vesting
- Security, Guardian, Emergency, Bootstrap, and Production upgrade controls

## Public Transparency Notice

This repository does not include operational deployment scripts, private environment files, wallet keys, internal deployment logs, or backend infrastructure files.

Operational scripts are intentionally excluded for security and intellectual-property protection.
