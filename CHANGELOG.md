# Changelog

All notable changes to the AurionXI Protocol will be documented in this file.

## [1.0.0] - 2026-08-06

### Added

- AurionXI Multi-Diamond Protocol public repository
- CoreDiamond, TokenDiamond, TradeDiamond, TreasuryDiamond, AnalyticsDiamond, and AIDiamond source code
- SBT contract source code
- CREATE2 deterministic deployment architecture
- BatchExecutor administrative workflow documentation
- Progressive security architecture documentation
- Mainnet deployment artifacts
- Testnet validation artifacts
- Public verification reports
- Engineering documentation under `docs/`

### Notes

- Operational scripts, private environment files, wallet keys, and internal logs are intentionally excluded from the public repository.
