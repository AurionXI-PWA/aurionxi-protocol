# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| v1.x | Yes |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly through the project's official communication channels.

Please do not disclose security issues publicly until they have been reviewed and addressed.

## Security Principles

AurionXI follows an engineering-first security model based on:

- Progressive Security Architecture
- Multi-Diamond isolation
- BatchExecutor administrative controls
- Guardian and emergency controls
- Production upgrade timelocks
- Multi-signature governance transition
- Public verification workflow
- Structured deployment methodology

## Scope

This policy applies to:

- Smart contracts
- Public deployment artifacts
- Engineering documentation
- Protocol infrastructure

Thank you for helping improve the security of AurionXI.
