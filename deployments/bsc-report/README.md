# BNB Smart Chain Mainnet Reports

This directory contains deployment reports generated after the successful Mainnet deployment of the AurionXI Protocol.

## Files

### deployment-report.txt

Chronological deployment execution log.

Includes deployment order, transaction hashes, gas usage, and deployment status.

---

### deployed-contracts.txt

List of all deployed contracts.

Includes deployed Diamonds, Facets, and corresponding Mainnet addresses.

---

### verification-report.txt

Contract verification report.

Contains verification status for deployed Diamonds and Facets together with engineering validation results.

---

These reports are published to improve transparency and assist developers, auditors, and independent reviewers.
