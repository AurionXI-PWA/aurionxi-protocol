# Deployment Artifacts

This directory contains deployment artifacts, deployment reports, and verification reports for the AurionXI Protocol.

## Directory Structure

### bsc-deployments/

Deployment JSON artifacts generated during BNB Smart Chain Mainnet deployment.

Contents include:

- Diamond deployment artifacts
- Facet deployment artifacts
- Deployment metadata

---

### bsc-report/

Deployment reports generated after Mainnet deployment.

Contains:

- deployment-report.txt
- deployed-contracts.txt
- verification-report.txt

These files provide deployment logs, deployed contract addresses, and verification results for independent review.

---

### bscTestnet-deployments/

Deployment JSON artifacts generated during BNB Smart Chain Testnet deployment.

Used for testing and validation before Mainnet deployment.

---

### bscTestnet-report/

Deployment reports generated during Testnet validation.

Contains:

- deployment-report.txt
- deployed-contracts.txt
- verification-report.txt

These reports document Testnet deployment, contract verification, and engineering validation.

---

The deployment reports are published for transparency and reproducibility.
